# Apple Hill Water Systems

Interactive site map and three water-source models for MathWorks Apple Hill: West Garage, AH-2 and AH-3.

Select a water source, explore equipment and reference photographs, or follow the guided water-flow tour. Components are not to scale; models illustrate the component assemblies.

This is a living reference that can be expanded with additional site information and photographs.

## Publish with GitHub Pages

This folder contains the complete static website, including editable HTML, CSS, JavaScript, model data and photographs. No installation or build step is needed.

1. Create a repository named `apple-hill-water-systems` using GitHub Desktop.
2. Copy all the contents of this folder into the new repository folder. Keep `index.html`, `.nojekyll` and `assets` at its top level.
3. Commit the files. Publish the repository to your GitHub account or company organization, with "Keep this code private" unchecked.
4. On GitHub, open the repository's Settings > Pages. Select "Deploy from a branch", branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub to display the published website link in Pages settings. Use that link to share the site.

## Future updates

Edit the files in the GitHub repository folder, commit the changes in GitHub Desktop, and click Push origin. GitHub Pages republishes the website at the same address. Keep a separate backup copy. Repository history can restore earlier versions.
